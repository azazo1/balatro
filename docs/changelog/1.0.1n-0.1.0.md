# Balatro v1.0.1n-0.1.0

Date: 2026-09-30

本仓库首次发布, 把 Windows 版 Balatro 发行包中的游戏资源重新打包为 macOS, Android 与
Windows 三个平台可直接运行的产物. 使用旧存档的用户请先阅读 Upgrade Notes.

版本号分两段: 前半 `1.0.1n` 是上游游戏版本, 后半 `0.1.0` 是本仓库的重打包版本. 这样同一份
游戏在后续修正打包问题时仍能发布新版本.

## Highlights

- macOS 产出 `Balatro.app`, 双击即可运行, 无需安装 LÖVE 或其它依赖.
- Android 产出签名 APK, 包名 `com.azazo1.balatro`, 存档放在外置存储便于备份.
- Windows 产出免安装的融合 exe, 解压即用, 不需要额外安装运行时.
- 三个平台共用同一份游戏资源, 且与发行包中的原始文件逐字节一致.
- 打包流程只用 Python 标准库, 在 macOS, Linux 与 Windows 上都能执行.

## Breaking Changes

- 三个平台均不包含 Steam 集成. 原发行的 Windows 版依赖 `luasteam.dll` 等原生模块,
  这些模块无法在 macOS 与 Windows 重打包产物中提供. 影响范围: 成就同步与 Steam 统计数据.
  迁移方式: 成就与进度改由本地存档记录, 游戏内成就通知照常显示; 想要 Steam 成就请继续
  使用官方 Steam 版本.

## Upgrade Notes

1. 备份现有存档. macOS 位于 `~/Library/Application Support/Balatro`, Windows 位于
   `%AppData%\Balatro`, Android 位于
   `/storage/emulated/0/Android/data/com.azazo1.balatro/files/save/Balatro`.
2. 从本页附件下载对应平台的产物并解压或安装.
   macOS 拖入 `/Applications`, Windows 解压后运行 `Balatro.exe`, Android 用 `adb install -r`
   或直接在设备上安装 APK.
3. 旧存档如需沿用, 将备份目录整体覆盖到上述新路径即可, 三个平台使用同一个身份标识
   `Balatro`, 可以直接迁移.
4. 验证方式是启动游戏, 确认主菜单出现且存档槽位中的进度可读取.

## Features

- macOS: 应用包使用 ad-hoc 签名并清除隔离属性, 首次打开无需额外放行; 图标由游戏内小丑牌
  素材生成.
- Android: 屏幕方向锁定横屏并允许随手机方向左右翻转; 提供五个密度的应用图标; 存档写入
  外置存储, 便于用文件管理器或 adb 备份.
- Windows: 额外提供带控制台窗口的 `Balatro-console.exe`, 便于查看 `print` 输出.
- 打包脚本会校验所用 LÖVE 运行时的 sha256, 避免运行时被替换或损坏后静默产出异常产物.
- 提供 `just macos dist`, `just android dist` 与 `just windows dist`, 以及按当前平台自动
  选择的 `just dist`.

## Bug Fixes

- Android: 游戏负载写入归档的 `assets/game.love`, 此前若写到归档根部会导致 APK 安装成功
  但启动即失败; 现在组装后会逐项复核归档条目.

## Performance

- 未包含 LuaJIT 相关的平台开关改动, Android 上的 JIT 行为与游戏原始代码保持一致.
