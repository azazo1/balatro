# Balatro v1.0.1o-0.1.1

Date: 2026-10-03

本版本修好 Windows 带 mod 包打开即崩溃, 并让 Android 支持系统分屏与小窗.

## Highlights

- Windows: CI 构建的带 mod 版可以启动, 不再在打开时报 Lua 语法错误.
- Android: 支持系统分屏与小窗.

## Upgrade Notes

1. 备份现有存档. 路径与 v1.0.1o-0.1.0 相同.
2. 从本页附件下载对应平台的产物, 覆盖安装或解压替换.
   Windows 用户若正在使用打不开的带 mod 包, 用这一版替换即可.
   macOS 把 `.app` 拖入 `/Applications`, Windows 解压后运行 `Balatro.exe`,
   Android 用 `adb install -r` 或在设备上安装 APK.
3. 验证: 启动游戏, 确认主菜单出现. 带 mod 的 Windows 包应能进入主菜单, 不再弹出语法错误.
   Android 可在系统分屏或小窗中打开游戏.

## Features

- Android: 打开 `resizeableActivity`, 系统允许分屏与小窗; 官方 LÖVE 运行时此前关掉了这一项.

## Bug Fixes

- Windows: 带 mod 的 CI 产物打开即报 `functions/UI_definitions.lua` 的
  `ambiguous syntax (function call x new statement)`. GitHub Windows runner 会把 lua
  检出成 CRLF, Steamodded 里按换行匹配的正则补丁因此未命中, 盲注图鉴界面留下残句.
  打包时把 lua 规范成 LF, 并强制仓库文本使用 LF.
