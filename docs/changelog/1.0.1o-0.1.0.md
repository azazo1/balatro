# Balatro v1.0.1o-0.1.0

Date: 2026-10-02

本仓库首次公开发布. 游戏升到上游 `1.0.1o`, 并把 Windows 发行包里的资源重打包为 macOS,
Android 与 Windows 三个平台可直接运行的产物. 每个平台同时提供原版与带 mod 两个包.
使用旧存档或 Steam 存档的用户请先阅读 Upgrade Notes.

版本号分两段: 前半 `1.0.1o` 是上游游戏版本, 后半 `0.1.0` 是本仓库的重打包版本.

## Highlights

- 游戏版本升到 `1.0.1o`: 新增 8 套联名皮肤, 制作人员界面增加 Collabs 页和高对比度开关,
  卡牌与规则与 `1.0.1n` 相同.
- 三个平台各出原版与带 mod 两份产物, 可同时安装, 存档互不影响.
- 带 mod 版内置 Steamodded, 以及可在游戏内自动玩的大模型 agent, 按局录像和回放.
- 内置 agent 在设置页填 endpoint, key 和模型即可运行, 支持 Chat Completions,
  OpenAI Responses 与 Anthropic Messages, 思考过程显示在画面顶部.
- 录像每局合成一份带声音的 `-full.mp4`; 主菜单选项里可以直接回放, Android 同样能用.

## Breaking Changes

- 三个平台均不包含 Steam 集成. 原发行的 Windows 版依赖 `luasteam.dll` 等原生模块,
  这些模块无法在重打包产物中提供. 影响范围: 成就同步与 Steam 统计数据.
  迁移方式: 成就与进度改由本地存档记录, 游戏内成就通知照常显示; 想要 Steam 成就请继续
  使用官方 Steam 版本.
- 全新存档的默认语言改为简体中文. 已有 `settings.jkr` 的用户不受影响, 也可在设置里改回.
- 原版与带 mod 版是两套应用, 包名和存档目录都不同. 不会自动沿用另一套的进度, 需要手动拷贝.

## Upgrade Notes

1. 备份现有存档.
   macOS 原版位于 `~/Library/Application Support/Balatro`,
   带 mod 版位于 `~/Library/Application Support/Balatro-Modded`.
   Windows 原版位于 `%AppData%\Balatro`,
   带 mod 版位于 `%AppData%\Balatro-Modded`.
   Android 原版位于
   `/storage/emulated/0/Android/data/com.azazo1.balatro/files/save/game`,
   带 mod 版位于
   `/storage/emulated/0/Android/data/com.azazo1.balatro.modded/files/save/Balatro-Modded`.
2. 从本页附件下载对应平台的产物. 文件名带 `balatro-modded-` 的是带 mod 版, 不带的是原版.
   macOS 解压后把 `.app` 拖入 `/Applications`, Windows 解压后运行 `Balatro.exe`,
   Android 用 `adb install -r` 或直接在设备上安装 APK.
3. 从 Steam 或本仓库更早的本地构建迁移存档时, 把备份目录整体覆盖到上表对应路径.
   注意 Android 原版的目录名是 `game`, 不是桌面上的 `Balatro`.
4. 验证方式是启动游戏, 确认主菜单出现且存档槽位中的进度可读取. 带 mod 版还应能看到
   主菜单的 MODS 按钮, 以及选项里的回放入口.

## Features

- 游戏: 新增联名皮肤 Assassin's Creed, Slay the Princess, Critical Role, Bugsnax,
  Vault-Tec, Dead by Daylight, Civilization VII, Rust; 制作人员界面可浏览 Collabs,
  图形设置增加高对比度.
- 打包: macOS 产出 `Balatro.app` / `Balatro-Modded.app`, ad-hoc 签名并清除隔离属性;
  Android 产出签名 APK, 包名 `com.azazo1.balatro` 与 `com.azazo1.balatro.modded`;
  Windows 产出免安装融合 exe, 另提供带控制台的 `Balatro-console.exe`.
- 三个平台的应用图标改用游戏自带的小丑脸, macOS 打包时套圆角矩形并按系统网格留边.
- 默认语言改为简体中文.
- Android 存档写在外置存储, 并补上目录权限, 可用文件管理器或 adb 备份; 退出时结束进程,
  再次进入不会卡在已退出的状态; 主菜单保留退出按钮.
- 带 mod 版在打包时应用 lovely 补丁并内置 Steamodded, 三个平台共用同一套 mod.
  vanilla-ui 让选牌组开局和 Run Info 的 Stake 页沿用原版界面.
  smods-fixes 让同一种子每次启动抽到相同 Boss, 并避免中文下打开 Steamodded 配置页崩溃.
- 内置 agent: 设置页可选关闭 / 外部 HTTP / 内置 loop; 可指定固定种子, 打法策略,
  思考强度, 单局 token 上限, 通关后回主菜单或进无尽, 以及打完一局后是否保留上下文继续.
  右上角 HUD 可暂停, 锁定操作, 并显示上下文占用. 每一步的解说会先显示, 读完后动作才生效;
  左侧记下每次工具调用. agent 能看到出牌计分过程和摸牌堆 / 弃牌堆.
- 外部 agent 仍可通过 HTTP 接口控制游戏, 默认关闭, 与内置 loop 互斥.
- 录像: 模组设置里可开关并调节清晰度, 帧率与码率. 每局一个文件夹, 局末合成 `-full.mp4`.
  桌面用 ffmpeg, Android 用系统 MediaCodec. Windows 录像不再弹出控制台窗口.
- 回放: 主菜单 选项 -> 回放. 人手动打的局和教程局也能回放. 节奏分原速 / 紧凑 / 快进,
  回放中途可切换, 可暂停和中止. 每局文件夹可从列表里删除.

## Bug Fixes

- Android: 游戏负载写入归档的 `assets/game.love`, 并在退出时结束进程, 避免退出后无法再次进入.
- Android: 存档目录外部不可见的问题已修, 文件管理器可以看到进度和录像.
- Steamodded: 中文翻译把选项说明写成单个字符串时, 打开配置页不再崩溃.
- Steamodded: 模组配置改走 `love.filesystem`, 不再跟进程工作目录写进应用包内.
- 商店与补充包: 补充包界面可以售出牌, 也可以使用消耗牌; 卡包里的牌按原版条件判断能否使用.
  商店消耗牌支持买下立即使用, 负片在槽满时也能买和选.
- 内置 agent: 打输后不再卡在游戏结束界面; 跳过标签开的补充包不再死等商店;
  背面牌不再把花色点数漏给观察层; 请求体去掉非法 UTF-8, 手册超长时不再整条请求被拒.
- 回放: Windows 上可以录像; 触摸长按 1.5 秒可中止; 回放列表与确认页的文字不再溢出.
- macOS: 应用图标不再比周围图标大一圈, icns 写入稳定.

## Performance

- macOS 录像走 videotoolbox, Android 走 MediaCodec 硬件编码.
- Windows 录像用 x264, 动画多时可能掉帧, 可在设置里降低清晰度或帧率.
