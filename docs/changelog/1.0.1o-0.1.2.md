# Balatro v1.0.1o-0.1.2

Date: 2026-10-03

本版本修好待办清单和轨道标签抽牌型不固定的问题, 并让导演和重构可以花 $10 重掷 Boss.
旧版录的回放若局中出现这两张, 在本版回放可能漂移, 请先阅读 Breaking Changes.

## Highlights

- 待办清单和轨道标签按 `G.handlist` 抽可见牌型, 同一种子跨端, 跨进程结果一致.
- 选盲注时可以花 $10 重掷 Boss (需导演剪辑版或重构).
- 进回放局之前点中止不再崩溃.

## Breaking Changes

- 待办清单与轨道标签的抽牌改为按 `G.handlist` 顺序, 不再用 `pairs(G.GAME.hands)`.
  旧实现依赖哈希表遍历顺序, 同一种子在不同平台或不同进程可能抽到不同目标.
  影响范围: 旧版录的回放, 只要局里出现待办清单或轨道标签, 在本版回放时可能在金钱或牌型等级处对不上并停止.
  回放摘要现在也会记下待办清单当前认的牌型, 目标一对不上立刻停, 不必等到发钱.
  迁移方式: 用本版重新录制这些局. 局里没有这两张的旧回放不受影响.

## Upgrade Notes

1. 备份现有存档. 路径与 v1.0.1o-0.1.1 相同.
2. 从本页附件下载对应平台的产物, 覆盖安装或解压替换.
   macOS 把 `.app` 拖入 `/Applications`, Windows 解压后运行 `Balatro.exe`,
   Android 用 `adb install -r` 或在设备上安装 APK.
3. 验证: 启动游戏, 确认主菜单出现. 带待办清单或轨道标签的新局, 跨端回放应对齐.
   旧版录的这类回放在本版播可能中途停止, 属预期.

## Features

- 选盲注时新增 `reroll_boss` 端点: 校验优惠券, 本底注次数与金钱, 等 Boss 栏换完或标签开包再返回.
  内置工具与商店 reroll 分开; 能掷时摘要写出价格. 人手动点按钮记成接口步骤, 旧回放的 press 仍能播.

## Bug Fixes

- 待办清单创建时和回合末重抽, 以及轨道标签在选盲注时抽牌型, 都改为 `ipairs(G.handlist)` 再看可见性.
- 进回放局之前点中止: 开局请求已经发出但还没进局时, 先等 start/load 完成再收尾;
  收尾时若转场还在, 最多再等 5 秒; 等盲注界面时 small 未建好或已拆掉不再直接取 UI.
