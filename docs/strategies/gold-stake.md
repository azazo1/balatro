# 金注高牌对子

内置 agent 的打法策略. 把下面 "策略正文" 整节复制到 模组 -> balatrobot 设置页的策略框, 下一次开始时生效.

来源: NGA 帖 "[Balatro]小丑牌大型攻略, 附小丑, 卡组评级" (tid 39751263, 2024-04). 按本仓库 1.0.1o 规则校正了过时数字, 小丑与牌组名改成游戏内中文名.

相对原帖必须改掉的点:

- 金注不减手牌上限, 默认仍是 8. 蓝注起弃牌 -1, 无牌组加成时每回合 2 次弃牌.
- 金注第 8 底注普通 Boss 目标约 40 万 (`200000 * 2`), 不是帖里的 36 万.
- 橙注 / 金注不会按底注提高补充包售价.
- 金注会出永恒, 易腐, 租用小丑; 原帖写于橙注重做之前.
- 八号球已改为计分的 8 有 1/4 概率给塔罗.

## 策略正文

本局打金注. 主打牌型只有高牌和对子. 分数来自小丑, 不要来自牌库和牌型等级.

### 开局

优先选蓝色牌组, 黄色牌组, 幽灵牌组. 其次彩绘, 方格, 废弃, 浮雕. 不要选黑色, 星云, 等离子.

- 蓝色: 多 1 次出牌, 前期更稳, 成长小丑长得更快, 余手也是钱.
- 黄色: 开局多 $10, 第一时间吃利息, 也是唯一值得为开局标签跳盲注的牌组. 第一张隐士有意义; 审判开出有用小丑就是天胡, 愚者还能再复制一次.
- 幽灵: 开局带妖法 (随机一张小丑变多彩), 商店能出幻灵, 负片率最高.
- 浮雕: 下限低上限高, 每打过一个 Boss 拿双倍标签, 适合镀金, 但 8 个底注刷不出负片标签很常见.
- 等离子: 金注不要选. 前期倍率牌几乎没用, 筹码小丑又少; 第 8 底注目标再乘 2, 成长筹码跟不上.

除黄色牌组外, 一个盲注都不要跳. 商店价值大于任何标签, 尤其是底注 1.

### 出牌与弃牌

金注只有 2 次弃牌, 大牌型不稳定. 只打高牌和对子, 顺带两对 / 三条也可以, 但不要为同花, 顺子, 葫芦, 四条去弃牌.

理由:

- 只打一种大牌型会被手臂 (牌型降级), 眼睛 (不能重复牌型), 公牛 (打出指定牌型金钱归零) 克死.
- 大牌型会削弱特技演员, 黑板, 老千小丑, 半张小丑, 绿色小丑, 搭乘巴士.
- 手牌越少, 出牌越小, 越不弃牌, 越好打: 特技演员 / 负片减手牌上限对高牌和对子几乎不是减益, 反而更容易触发黑板.
- 出牌远比弃牌值钱. 窃贼 (弃牌 -2, 出牌 +3) 是神卡, 出牌可以当弃牌用, 还有分数, 经济和成长.

底注 1:

- 没拿到成长小丑时, 可以用 2 次弃牌和前面几手去攒一个大牌型, 最后一手打出过关.
- 起手有绿色小丑或搭乘巴士, 只打对子就能过. 1 级对子是 `10 x 2`; 倍率成长到 +4 时一对大约 `30 x 6 = 180`, 够过 450 和 600.
- 三个商店还没有任何筹码 / +倍率小丑, 这局基本没了, 不必硬凹.

不要为了凑牌去把人头牌打出去, 除非这一手必须过关. 绿色小丑和搭乘巴士都讨厌弃牌和打人头.

### 花钱

分数来源: 小丑 > 手牌 > 牌型. 钱的顺序: 小丑 > 塔罗 / 幻灵 > 星球.

- 不要买星球补充包. 商店里刷出的 $3 星球可以买. 多 $10 时优先刷新商店找核心小丑, 不要开星球包.
- 不要把战力堆进牌库 (无限红蜡封钢铁, 男爵 + 哑剧演员那套). 金注成型慢, 且会被禁花色, 植物 (禁人头), 翠绿之叶单防.
- 前期哪怕是 +50 筹码或白板小丑的 +4 倍率也要买, 用来活过底注 3, 4.
- 战力够用时尽量把利息拿满 ($25). 算得出下一盲注明显打不过, 再把钱砸进刷新.
- 前期更想看到普通品质, 不要为买不起的稀有牌跳盲注. 裸奔篝火, 棒球卡对底注 1 没帮助.

### 小丑构成

理想后期: 1 张筹码, 1-2 张 +倍率, 其余 x 倍率. 金注第 8 底注普通 Boss 约 40 万, 按 4 手算每手约 10 万. 参考: `300 筹码 x 50 倍率 x3 x2 ≈ 9 万`, 略低于每手目标, 缺的用成长, 皇后 / 玻璃, 或篝火 / 吸血鬼把 x 倍率顶上去. 牌力够强时第 5 槽可以拿来镀金.

缺哪块补哪块: 基础倍率只有 20, 就堆更多 x 倍率, 或用皇后给牌 +倍率; 缺筹码就找教皇和石头牌.

金注贴纸:

- 易腐适合前期过渡, 5 个实际回合后失效, 到期卖掉换真正的核心.
- 租用每回合 -$3, 只有战力或经济明显超过这个成本才留. 核心成长小丑尽量不要租用.
- 永恒不能卖. 垃圾永恒不要占核心位. 疯狂只在核心都是永恒时才考虑.

### 必拿与可拿

任何时候无脑拿: 特技演员 (+300 筹码, -2 手牌上限, 高牌 / 对子下几乎无代价, 还能稳定触发黑板), 黑板, 卡文迪什, 老千小丑, 篝火, 吸血鬼, 蓝图, 头脑风暴, 照片.

稳定 x3:

- 黑板: 手牌里没有红桃和方块就 x3. 万能牌在手里算黑牌. 镀金和钢铁优先给黑桃和梅花, 当时没有黑板也这样. 开塔罗包没更好选择时优先转黑桃 / 梅花. 方块或红桃被削弱时, 即便留在手里也能触发黑板.
- 卡文迪什: 只有大麦克香蕉自己灭绝才出, 仪式匕首 / 疯狂吃掉不算. 普通品质.
- 老千小丑: 本回合不是第一手就 x3.

突破 x3 上限: 篝火, 吸血鬼. 操作对了打 Boss 可以到 x10 以上, 一张顶两张, 镀金最佳伴侣.

烧焦小丑: 等于可控的免费星球, 升级写在牌型上, 随时可卖, 还能省掉筹码和基础倍率的格子. 可被蓝图复制, 弃牌时升两级. 占一个经济位去养; 和绿色小丑抢位时优先绿色小丑. 后期卖掉换 x 倍率. 有烧焦也不等于可以不带筹码 / 倍率, 眼睛和公牛仍要能换牌型硬钢.

乌合之众: 前期最好的普通小丑, 能刷出成长小丑, 废的卖掉换钱, 大麦克灭绝还能出卡文迪什, 生成的小丑可以带版本 (有空位才能出负片). 底注 3, 4 就要卖, 后面再出价值低, 所以不是整局无脑拿.

成长核心, 越早越好, 前两个商店拿到绿色小丑 / 搭乘巴士 / 方形小丑就可以专心打小牌型:

- 强: 绿色小丑, 搭乘巴士, 超新星, 方形小丑 (普通, 好刷). 蓝色牌组下更强, 必要时把 x 倍率放到左边, 故意少留余手, 多打几手去养成. 中期目标大约 +30 到 +50 倍率, 筹码成长到第 8 底注大约 200-300.
- 同样能拿但更稀有: 备用裤子, 闪示卡, 城堡, 小小丑.
- 稍差但刷到也拿: 占卜师 (补充包贵, 长得慢), 仪式匕首 (必须空一个格子), 跑步选手 (顺子不稳), 太空小丑 (不如烧焦), 红牌 / 斗牛 / 提靴带 (要牺牲经济, 少刷新就少核心).

其他 x 倍率: 拉面和二重奏稳定 x2, 优秀. 驾驶执照能拿但不如黑板 / 老千小丑. 全息影像要靠开包长, 配合 DNA / 证书上限高. 回溯依赖跳盲注, 本策略基本不跳, 别拿. 钢铁小丑和玻璃小丑把战力放牌库, 不符合本策略.

经济小丑普遍每回合约 $4, 中前期出了就拿: 延迟满足, 9 霄云外, 鸡蛋, 黄金小丑, 待办清单, 邮件回扣. 火箭和冲向月球稀有, 火箭还要养, 可能没养大就卖掉换核心.

过渡小丑, 前几个商店出了必拿: 贪婪小丑 / 色欲小丑 / 愤怒小丑 / 暴食小丑, 小丑, 开心小丑 / 奸诈小丑, 滑稽小丑 / 精明小丑, 偶数史蒂文 / 奇数托德, 对讲机, 学者, 微笑表情, 恐怖面孔, 半张小丑, 旗帜, 冰淇淋, 爆米花, 大麦克香蕉. 前期 +50 筹码或 +4 倍率就能活.

第 8 底注刷出骷髅先生无脑拿一个.

不要当核心养:

- 男爵, 哑剧演员, 血石: 先结算打出的牌, 再手牌, 最后小丑. 高牌 / 对子基础倍率极低, 血石触发 3 次也只是 `2 x2 x2 x2 = 16`, 不如半张小丑.
- 疯狂: 不稳定, 对镀金几乎没用; 没东西吃也每回合 +x0.5, 但核心必须都是永恒才敢拿.
- 模具小丑: 碰到绯红之心这局白玩.
- 方尖石塔: 能用但操作重. 前半局狂打一种牌型 (对子最好) 到 20-30 次, 之后再也不打它, 让高牌次数涨得尽量慢. 方格牌组前期能稳定同花, 相对好用. 其他牌组容易失误, 不要主动追.

### 摆放

结算从左到右: 先打出的牌, 再手里的牌, 最后小丑.

- 小丑: +倍率在左, x 倍率在右, 筹码无所谓. 棒球卡本身位置无所谓, 把罕见牌放到 +倍率右边. 蓝图 + 窃贼: 进盲注时复制窃贼拿 +6 出牌, 再挪走蓝图出牌次数不会减. 弃牌时复制烧焦小丑升两级.
- 出牌: 同样先 +倍率再 x 倍率. 倍率牌在左, 玻璃 / 多彩在右. 斐波那契 + 照片这种按出牌顺序结算的, 把要吃 x 倍率的人头放到最右边, 例如 KA234 同花打成 A234K.
- 手牌: 致胜之拳, 射月这种 +倍率在左, 钢铁牌, 男爵这种 x 倍率在右.

### 商店节奏

底注 1 每个商店都看. 不要因为没有塔罗包 / 商店免费 / $15 就无限重开或连跳两个盲注裸奔.

前中期不跳盲注. 成长小丑越早拿到作用越大, 牌的成长速度跟得上分数膨胀.

有半张小丑等过渡战力时先活着, 钱先吃利息; 算出下一关明显不够再全额刷新找加成和成长.
